# 矩阵与空间变换 · 用一个点和一支箭头看懂

用**最小的认知模型**教矩阵旋转与空间变换：不背公式，只盯两样东西——

- **一支箭头**（初始沿 +x 的单位箭头）→ 旋转矩阵的每一列，就是箭头们旋转后"尖端读数"的登记表
- **一个点**（原点/或任一点 P）→ 坐标不是编号，是"混合箭头的配方比例"；平移只是把"原点"这个点搬家

在此模型上展开：齐次坐标与 4×4 布局 `[箭头|箭头|箭头|原点]`、空间=点+基、主动/被动两种读法、世界/本地/父/实例/摄像机/屏幕空间互转、嵌套链式变换（离点最近的矩阵在最右）、真实透视投影一路算到屏幕像素。

## 特点

- 🎯 **极简模型优先**：先 2D（两支箭头讲透 cos/sin 从哪来），再补第三支箭头进 3D——规则一条没加，只是多抄一列
- 🖼️ **6 个交互演示，其中 4 个真 3D**（自研 Canvas 3D 微引擎：轨道相机 + 透视投影 + 深度排序，无任何依赖）：
  1. 箭头旋转器（2D）——矩阵第一列 = 橙色箭头尖端
  2. 点的配方（2D）——平行四边形调合 + 逐步算术展开
  3. 3D 帧驾驶舱——yaw/pitch/roll + 平移，各动 4×4 的哪一列
  4. 两套读数（3D）——同一 P 的世界/本地读数、配方阶梯、M 与 M⁻¹ 对照
  5. 3D 实例阵列——一套本地数据 × N 套"点+箭头"
  6. 3D 全链路推演器——子本地→父本地→世界→摄像机→NDC→像素，真实透视除法（÷w），含视锥、裁剪提示与"交换连乘顺序"对照实验
- 🔢 **所有数值现场计算**：矩阵逐项、每站读数、NDC、像素坐标全部实时真算，可手工复算
- 🎮 **引擎对照**：ISMC/Niagara Local Space/材质 Transform 节点/RelativeLocation，UE 左手系 vs 教学右手系的差异标注
- 🌙 暗色/亮色主题、侧栏 scrollspy、阅读进度、随堂小测、单文件零依赖离线可开

## 约定

- 列向量约定 `M·p`，原点在最后一**列**（行向量差异见第 6 章坑位表）
- 3D 演示为右手系、z 朝上（x 前、y 左、z 上）；UE 为左手系（x 前、y 右、z 上）
- 摄像机空间沿用 OpenGL 惯例：视线 = −z，NDC 三轴 ∈ [−1,1]

## 使用

双击 `index.html` 即可（或 `python -m http.server` 后浏览器打开）。3D 演示：拖空白处旋转视角、滚轮缩放；圆点/空心圈可直接拖动。
